# OIP 画廊：开机自启 + 控制台（使用说明）

## 现在有两个东西，它们互不干扰

1. **画廊**：看图的那个网站，地址固定 `http://127.0.0.1:5173/`
2. **控制台**：桌面上的「OIP 画廊控制台」图标。双击它会打开一个面板，用来看画廊活没活着、停止或重启它、开关开机自启

控制台只是个遥控器。关掉浏览器、点「退出控制台」，画廊照样在后台跑。

---

## 日常怎么用

### 看状态、打开画廊

双击桌面「OIP 画廊控制台」，浏览器会自动打开面板，不用等、不用登录。

面板最上面一块显示现在的状态：**运行中 / 已停止 / 正在启动 / 端口被占用 / 启动失败**，下面跟着 PID、端口、启动时间。

点「**打开画廊**」直接进看图页面。

### 停止、重启

就在同一块里的「停止」「重启」。

- 停止会先问你一句，防止手滑
- 重启是停完再起，中间大约 3～6 秒打不开页面

### 开机自动启动

第二块一个开关，打开就是开启，关掉就是取消，改完立刻生效。

- **打开**：以后每次登录 Windows，等大约 15 秒，画廊自动在后台起来，不弹任何窗口
- **关闭**：下次开机不再自动起（这次已经在跑的不受影响）

### 出错时看日志

第三块「运行日志」点开，能看到服务最近的输出，出错的行会标红，底部有两个按钮：复制日志路径、复制最后一条错误。

---

## 三个要记住的点

1. **「关掉控制台」不等于「关掉画廊」**。面板最下面那个「退出控制台」只关遥控器，画廊还在跑。
2. **开机自启只负责启动，不负责盯着**。万一后台被关掉了，双击控制台点「启动」就行。
3. **地址永远是 `http://127.0.0.1:5173/`**，可以直接收藏成书签，不打开控制台也能看图。

## 文件都在哪

| 位置 | 是什么 |
| --- | --- |
| 桌面「OIP 画廊控制台」 | 双击入口（快捷方式） |
| `tools\oip-daemon\open-console.vbs` | 入口脚本，快捷方式指向它 |
| `tools\oip-daemon\gallery-service.mjs` | 启动画廊的程序 |
| `tools\oip-daemon\daemon.mjs` | 控制台服务 |
| `tools\oip-daemon\console.html` | 控制台页面 |
| `.oip\daemon\service.log` | 画廊日志 |
| `.oip\daemon\console.log` | 控制台日志 |
| 启动文件夹 `OIP 画廊服务.vbs` | 开机自启项 |

启动文件夹的完整路径：
`C:\Users\xuhao\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup\OIP 画廊服务.vbs`

## 想彻底不要了

1. 控制台里关掉「开机自动启动」（或者直接删掉上面那个 `OIP 画廊服务.vbs`）
2. 删掉桌面「OIP 画廊控制台」快捷方式
3. 控制台里点「停止」
4. 删掉 `tools\oip-daemon\` 整个目录
5. 这一步的文件已经记进项目历史，删掉目录后在项目里提交一次，历史里也就清掉了

做完这几步，项目就回到只有 `start.bat` 手动启动的状态，没有别的残留。
